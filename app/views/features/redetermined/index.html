Feature: Redetermined cases

Mural link
Jira ticket

This feature allows back office users to redetermine a case.

Once a case officer updates the case status to 'Under High Court Team', and clicks the redetermined button, the system will automatically:

  1. create a new case with the same case reference, appended with '/RD'
  2. set the new case's status to 'New' and copy the original case details
  3. lock the original case, mark its decision as quashed, and set its status to 'Redetermined'
  4. show the original case's decision as quashed on the original front office page, with interim text saying a redetermined case is pending
